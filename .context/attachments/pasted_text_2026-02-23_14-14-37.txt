### 3. Query Convex

**Fichier : `packages/convex-functions/src/kitchenTickets.ts`**
- Créer query `getForDisplay(storeId)` qui retourne :
  - `preparing` : tickets avec status in ["new", "in_progress"], triés par createdAt ASC
  - `ready` : tickets avec status = "ready", pickedUpAt = null, dans la fenêtre auto-dismiss, triés par readyAt DESC
  - `displayConfig` : autoDismissEnabled + autoDismissMinutes
  - `storeBranding` : logoUrl + name du store
  - `serverNow` : timestamp serveur pour alignement
- Ne retourner que les champs minimaux : _id, orderNumber, status, createdAt, readyAt
